# 급여명세서 발급 자동화 (별동수)

> 🎨 **Figma 다이어그램:** https://www.figma.com/board/nfeVKOUMd1jCqiXGmgjmsZ
> (파랑=별동수 자동 · 노랑=대표 판단/승인 2곳 · 회색=세무사)

`2026_sal` 스프레드시트의 **"급여명세서" 탭 → 직원별 PDF 생성 → 발송**을 자동화한다.
Autocrat가 하던 머지를 같은 템플릿으로 Apps Script가 직접 수행하되, **발송 직전 대표 승인 게이트**를 둔다.

## 전체 데이터 흐름 (이 자동화의 위치)

```
[단기직원 근무일지 시트]            (김상희·김지민, 월별 근무 입력)
   └─ 단기직원 급여예상액 ─┐
정규직 급여 기준 ───────────┤→ 세무사(조성완) 발송
                            │     └─ 급여대장/급여명세서 회신 (정규직 + 단기직원)
                            ▼
        2026_sal "급여명세서" 탭에 복사 (해당월 행)   ← 선행: 단기직원 근무일지가 항상 관여
                            │
                            ▼
        ★ 별동수(이 스크립트): PDF 생성 → 승인 → 직원 발송 → 검증
```

- **선행(front half)** = 단기직원 근무일지 → 세무사 왕복: `../monthly-payroll-tax.md` 워크플로우.
- **후행(back half, 이 폴더)** = "급여명세서" 탭 → 발송: 아래 Apps Script.

## 산출물 (확인된 현행)
- 직원별 PDF: `{month}, {name} {직급}님  2026년 코리아스픽스 급여명세서.pdf` → Drive 폴더 `1Xl_clzgT7dUqVpwqwH3TUxo6FyTeW_wi`
- 발송 메일: 제목 `{name}님, 스픽스 {month} 급여명세서입니다.` + 본문(이달의 인사말) + PDF 첨부, Reply-To `playinthesky@kspeaks.kr`

## 동작 (승인 게이트)
1. **`1) PDF 생성 + 초안`** — 행마다 PDF 만들고 Gmail 임시보관함에 초안 작성. **발송 안 함.**
2. 대표가 초안/PDF 검토.
3. **`2) 검토 후 발송`** — `READY` 행만 실제 발송 + 상태 기록.

안전장치
- **이메일 검증**: 빈/형식오류 행은 건너뛰고 `!!오류` 표시 (과거 *'잘못된 이메일 / 수신자 없음'* 실패 재발 방지).
- **TEST_MODE=true**: 모든 메일을 대표 본인에게만 보냄 → 실전 전 전 과정 검증.
- **멱등**: `Emails Sent`인 행은 다시 안 보냄. 실패 행만 `retryFailed`로 재시도.

## 설치 (대표님, 1회)
1. `2026_sal` 열기 → **확장 프로그램 → Apps Script**.
2. `Code.gs` 내용을 붙여넣고 저장.
3. 시트 새로고침 → 상단 **`🤖 별동수 급여명세서`** 메뉴 생김.
4. 처음 실행 시 권한 승인(스프레드시트·Drive·Gmail).
5. **TEST_MODE=true**로 한 번 돌려 본인 메일로 전 직원분 PDF·메일 확인.
6. 이상 없으면 `CONFIG.TEST_MODE = false`로 바꿔 실전 발송.

## 설치 전 확인할 CONFIG
- `TEMPLATE_DOC_ID` — ✅ **검증됨**: 실제 급여명세서 템플릿 Doc. 본문 `<<태그>>`가 "급여명세서" 탭 컬럼명과 정확히 일치(`<<month>>`·`<<기본급>>`·…·`<<차인지급액>>`).
- `DATA_SHEET_NAME` — 탭 이름이 정확히 `급여명세서`인지.
- `OUTPUT_FOLDER_ID` — PDF 저장 폴더.

### 템플릿 자체의 알려진 이슈
- 템플릿 본문 제목이 **`2025년 <<month>> 급여명세서`** 로 하드코딩됨(연도 고정). 파일명·메일은 2026년이지만 PDF 본문 제목은 2025년으로 나감 → 템플릿 Doc에서 `2025` → `2026`(또는 `<<연도>>` 토큰) 수정 권장.
